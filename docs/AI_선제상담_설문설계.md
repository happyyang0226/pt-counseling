# AI 선제 상담 설문 설계 (물리치료과 1학년 지도 상담)

## 1. 전체 흐름

1.  학생이 설문 문항을 클릭해서 답해요 (긴 글 없이).

2.  서버(Vercel 함수)가 답을 보고 문항에 미리 정한 등급을 먼저 판정해요.

3.  등급에 따라 처리해요.

    - 🟢 일반: AI(Claude API)가 바로 공감과 실천 팁을 줘요.

    - 🟡 관심: AI가 답하고, 교수 화면에 노란색으로 표시돼요. 다음 상담
      때 꼭 다뤄요.

    - 🔴 긴급: AI는 조언하지 않아요. 교수에게 즉시 알림이 가고,
      학생에게는 "교수님이 곧 연락드릴게요"라는 안내와 위기 연락처가
      나와요.

4.  최종 등급은 "문항 등급"과 "AI 판단" 중 **더 높은 쪽**으로 해요. AI가
    등급을 낮출 수는 없어요.

## 2. 필수 상담 3회 일정

| 회차 | 시기            | 초점                          |
|------|-----------------|-------------------------------|
| 1회  | 학기 초 (3~4주) | 적응, 생활, 진로 기초         |
| 2회  | 중간고사 뒤     | 성적, 공부 방법, 스트레스     |
| 3회  | 기말 전         | 학기 돌아보기, 다음 학기 계획 |

매 회차마다 공통 기본 설문(A)을 먼저 하고, 고른 분야의 세부 설문(B)으로
넘어가요.

## 3. 공통 기본 설문 (A, 매 회차)

| 번호 | 문항                              | 답 방식       | 등급 규칙          |
|------|-----------------------------------|---------------|--------------------|
| A1   | 요즘 전반적인 기분은 어때요?      | 1~5점         | 1점 → 🟡           |
| A2   | 지금 고민의 크기는?               | 1~5점         | 4점 → 🟡, 5점 → 🔴 |
| A3   | 상담하고 싶은 분야 (여러 개 가능) | 7개 분야 선택 | 없음               |
| A4   | 원하는 상담 방식                  | 온라인 / 대면 | 없음               |
| A5   | 교수님과 직접 이야기하고 싶나요?  | 예 / 아니요   | 예 → 🟡            |

## 4. 분야별 세부 설문 (B)

### 공부·성적

- 🟢 공부 방법을 잘 모르겠어요

- 🟢 전공 과목이 어려워요 (해부학, 생리학 등)

- 🟢 시험 준비 계획을 세우고 싶어요

- 🟡 성적이 많이 떨어졌어요

- 🟡 수업에 자주 빠지게 돼요

### 진로·취업

- 🟢 물리치료사 진로가 궁금해요

- 🟢 국가고시 준비 방법이 궁금해요

- 🟢 편입·진학이 궁금해요

- 🟡 전공이 나와 맞는지 모르겠어요

### 학교생활

- 🟢 학교 시설이나 제도 이용이 궁금해요

- 🟢 동아리, 학과 활동이 궁금해요

- 🟡 학교에 적응하기 힘들어요

- 🔴 학교를 그만두고 싶어요 (휴학·자퇴 고민)

### 친구·대인관계

- 🟢 친구를 사귀기 어려워요

- 🟢 조별 과제가 힘들어요

- 🟡 친구와 갈등이 계속돼요

- 🟡 늘 혼자 있는 것 같아요

- 🔴 괴롭힘이나 따돌림을 당하고 있어요

### 마음·스트레스

- 🟢 스트레스를 푸는 방법이 궁금해요

- 🟡 잠을 잘 못 자요

- 🟡 자주 불안하거나 우울해요

- 🟡 의욕이 거의 없어요

- 🔴 너무 힘들어서 다 포기하고 싶어요

- 🔴 나를 해치고 싶은 생각이 들어요

### 경제·생활

- 🟢 장학금 제도가 궁금해요

- 🟢 아르바이트와 공부를 같이 하는 방법

- 🟡 아르바이트 때문에 수업에 지장이 있어요

- 🟡 생활비나 등록금이 많이 부담돼요

- 🔴 당장 생활이 어려울 정도예요

### 잘 모르겠어요

- 🟡 그냥 이야기하고 싶어요 → 교수 직접 상담으로 연결

## 5. 안전 원칙

- 🔴 문항은 AI 판단과 관계없이 **무조건** 교수에게 즉시 알림이 가요
  (화면 빨간 배지 + 이메일).

- 🔴 화면에는 위기 연락처를 항상 보여 줘요: 자살예방상담 109,
  정신건강위기상담 1577-0199, 교내 학생상담센터 (번호는 교수가 설정
  화면에서 입력).

- AI 답변 맨 아래에는 "AI의 답변은 참고용이에요. 교수님이 곧
  확인할게요"라는 문구를 붙여요.

- AI는 진단하지 않아요. 약이나 치료를 권하지 않아요. 짧게(5문장 안팎)
  공감하고 실천 팁을 줘요.

- API 키는 Vercel 서버 환경변수에만 둬요. 학생 화면 코드에는 절대 넣지
  않아요.

- 학생 원문과 AI 답변은 모두 기록하고, 교수가 나중에 볼 수 있어요.

## 6. 코드 방에 줄 프롬프트

pt-counseling 저장소에 'AI 선제 상담 설문' 기능을 추가해 줘. 이 문서의
2~5절(회차, 문항, 등급, 안전 원칙)을 그대로 구현 기준으로 써.  
  
1. 설문 문항과 등급(green/yellow/red)은 DB 테이블 cs_survey_items에
넣고, 교수가 관리 화면에서 문항과 등급을 수정할 수 있게 해 줘.  
2. 학생 답변은 cs_survey_responses에 저장해. 회차(1~3), 고른 분야, 상담
방식(온라인/대면)도 같이 저장해.  
3. Vercel 서버 함수 /api/ai-feedback 을 만들어. ANTHROPIC_API_KEY는
환경변수로만 읽어.  
- 먼저 문항 등급으로 판정하고, AI에게도 green/yellow/red를 판단하게 해서
더 높은 쪽을 최종 등급으로 해.  
- red면 AI 조언을 만들지 말고, 교수 알림(화면 배지 + 이메일)과 위기
연락처 화면만 보여 줘.  
- green/yellow면 공감 + 실천 팁 5문장 안팎, 진단이나 약 권유 금지, 끝에
'AI 답변은 참고용' 문구.  
4. 교수 대시보드에 등급별 색상 표시, red 우선 정렬, '확인함' 버튼을 넣어
줘.  
5. 교내 학생상담센터 전화번호는 cs_settings에서 교수가 입력하게 해 줘.  
6. 모든 새 테이블은 cs\_ 접두사, RLS 적용. 기존 데이터는 지우지 마.  
7. 작업 전에 계획을 먼저 보여 주고 내가 확인하면 진행해. 끝나면 green,
yellow, red 각각 테스트 학생으로 흐름을 점검해 줘.
